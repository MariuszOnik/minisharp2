# MiniSharp (nowy rdzeń)

Mały język w stylu C#, który kompiluje się i uruchamia na Nintendo 3DS – z edytorem kodu i edytorem grafu na
konsoli. To repo to **przebudowa** starego MiniSharp: rdzeń niezależny od gier, a gry i większe dodatki jako moduły.

Stan: etap 0 (przegląd i plan). Zobacz [PLAN.md](PLAN.md), [docs/PRZEGLAD.md](docs/PRZEGLAD.md),
[docs/ARCHITEKTURA.md](docs/ARCHITEKTURA.md).
