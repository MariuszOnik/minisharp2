# MiniSharp (nowy rdzeń)

Mały język w stylu C#, który kompiluje się i uruchamia na Nintendo 3DS i w przeglądarce – z edytorem kodu i edytorem
grafu. To repo to **przebudowa** starego MiniSharp: rdzeń niezależny od gier, a gry i większe dodatki jako moduły.

Stan: etap 1 (język + testy na PC; `make test`, na Windows `tools/test.ps1`). Nowe sesje: zacznij od [CLAUDE.md](CLAUDE.md). Zobacz [PLAN.md](PLAN.md), [docs/PRZEGLAD.md](docs/PRZEGLAD.md),
[docs/ARCHITEKTURA.md](docs/ARCHITEKTURA.md).
